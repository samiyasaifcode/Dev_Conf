# **AI prompt for generating new section**

**Role:** Act as a senior UI/UX designer and frontend developer.

**Context:** I am building a landing page for a massive developers' conference (4,000+ attendees) using only raw HTML5 and CSS (no frameworks like Tailwind or Bootstrap). I have already built the Navigation, Hero, Speakers, and Pricing/Booking sections.

**Task:** Generate the ideas and code for several new, highly engaging sections to be placed below my existing content. The goal is to keep users engaged, provide necessary information, and drive ticket conversions.

**Sections Required:**

*   **Engagement & Value Funnel:** Create sections that convince the user to stay or buy (e.g., a "Why Attend" grid, an FAQ section, and a Newsletter Subscribe CTA).
*   **Social Proof:** A dedicated Testimonials and Ratings section showcasing reviews and star ratings from past attendees.
*   **Location Details:** A Venue section that includes the physical address, a brief description, and a fully embedded Google Map.

**Design Constraints:**

*   **Consistency:** Flawlessly integrate with the existing theme. Inherit the typography, color palette, padding/margins, and styling (e.g., 20px border-radiuses) from my provided code.
*   **Color Scheme:** The main background for these new sections must be white, utilizing the existing brand colors (blues, dark navy, soft grays) for accents, text, and cards.
*   **Tech Stack:** Strictly HTML5 and CSS only.
